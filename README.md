# Smart Expense Tracker

A clean and simple expense tracker application built with React and Material-UI. 

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

The application will be available at `http://localhost:3000`.

## Features
- Add and categorize your expenses and income.
- View total balance in real-time.
- Responsive design.
